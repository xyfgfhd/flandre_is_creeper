## 版权声明
- Flandre Fumo 的模型（纹理与渲染器）来源于项目[Fumo-Mcreator](https://github.com/KosherKomeiji/Fumo-Mcreator "Fumo-Mcreator的github页面")
- 苦力怕的引信声来源于youtube中的[物凄い狂っとるフランちゃんが物凄いうた的二创版本](https://www.youtube.com/watch?v=yle5VARnkk4 "youtube视频页面")（以下简称为引信声）
## 项目介绍
- 将苦力怕的模型替换为Flandre Fumo并修改了碰撞箱，使其更符合模型
- 将引信声替换为物凄い狂っとるフランちゃんが物凄いうた的二传版本
- 增加了引信时间使其与引信声的长度基本一致
- 使引信剩余时间不会因离开索敌范围而回退而是继续计时
- 修改了苦力怕在引信倒计时的缩放
